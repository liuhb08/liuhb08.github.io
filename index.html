DSH-gstorage

A private, single-user OAuth client that connects rclone to the owner's own Google Drive.

Application name: DSH-gstorage

DSH-gstorage exists to let the owner of this application read their own Google Drive from their own computer through rclone. It has exactly one user: the account owner. It is not distributed, published, or offered to anyone else.

  • Application name: DSH-gstorage
  • Users: one (the account owner)
  • Google API scope requested: drive.readonly only
  • Data collected, shared or sold: none
  • Analytics, tracking, cookies: none
