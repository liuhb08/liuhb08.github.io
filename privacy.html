Privacy Policy — DSH-gstorage

Application name: DSH-gstorage. Last updated: 2026-10-02.

What this application is

DSH-gstorage is a private OAuth client used by a single individual to connect rclone, running on that individual's own computer, to that same individual's own Google Drive account. It has no other users and is not offered as a service to anyone.

What data is accessed

DSH-gstorage requests only the drive.readonly scope, which allows listing file names and downloading file content from the owner's own Google Drive. It cannot create, modify, rename, share, or delete any file.

What data is collected, stored, or shared

None. No data is collected, no data is transmitted to any third party, and no analytics or tracking of any kind is used. OAuth credentials (an access token and a refresh token) are stored locally on the owner's own machine, in a file readable only by the owner, and are never shared.

Where data goes

Data flows only between the owner's computer and Google Drive, over the Google Drive API. Nothing passes through this website; this website stores or processes no data and sets no cookies.

Revoking access

The owner can revoke access at any time from the Google Account permissions page (myaccount.google.com/permissions), after which the stored credentials stop working.

Contact

Reach the owner of DSH-gstorage through the repository that hosts this page.
